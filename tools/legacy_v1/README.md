# Legacy Jupyter Book v1 configuration

Kept for reference only. The repo is now configured for Jupyter Book
**v2** (MyST-MD, Node.js) — see `../../myst.yml` at the repo root.

If you want to go back to v1:

1. `pip install -r requirements-jupyterbook.txt`
2. Move `_config.yml` and `_toc.yml` back to the repo root.
3. Build with `jupyter-book build .` (note the **hyphen**).
